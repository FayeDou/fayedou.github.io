abstract: >-
  This paper introduces Aqua-Sim: Next Generation, an improved underwater sensor network (UWSN) simulator built by transitioning Aqua-Sim 2.0 from NS-2 to NS-3 for better memory management and unified programming. The new version enhances performance, preserves existing protocol functionality, and adds features to more accurately model underwater environments and phenomena.
